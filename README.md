# 📝 To-Do List — Full Stack

Aplicação web de lista de tarefas desenvolvida como projeto de estudo durante o microlearning **"Sua primeira aplicação web completa, rodando no seu computador"**, oferecido pela [TrivalApps](https://trivalapps.com/).

O projeto teve como objetivo colocar em prática os fundamentos do desenvolvimento full stack, integrando um frontend em Vue.js, uma API desenvolvida em C#/.NET e um banco de dados MongoDB.

A aplicação permite visualizar e cadastrar tarefas por meio de uma interface web que se comunica com a API para consultar e persistir os dados.

## 🚀 Tecnologias utilizadas

**Frontend**
- [Vue.js](https://vuejs.org/)
- JavaScript
- HTML5
- CSS3

**Backend**
- [C#](https://learn.microsoft.com/pt-br/dotnet/csharp/)
- [.NET](https://dotnet.microsoft.com/)

**Banco de dados**
- [MongoDB](https://www.mongodb.com/)

## ✨ Funcionalidades

- Listagem de tarefas cadastradas (GET).
- Cadastro de novas tarefas (POST).
- Comunicação entre frontend e backend por meio de requisições HTTP.
- Persistência dos dados no MongoDB.

## 🏗️ Arquitetura da aplicação

A aplicação é composta por três partes principais:

- **Frontend:** desenvolvido em Vue.js, responsável pela interface e interação com o usuário.
- **Backend:** API desenvolvida em C#/.NET, responsável pelo processamento das requisições.
- **Banco de dados:** MongoDB, utilizado para armazenar as tarefas.

### Fluxo de comunicação

1. O usuário interage com a interface Vue.js.
2. O frontend envia uma requisição HTTP para a API.
3. A API processa a solicitação e consulta ou cadastra os dados no MongoDB.
4. A resposta é enviada ao frontend para apresentação das informações.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de uma aplicação web full stack.
- Desenvolvimento de interfaces com Vue.js.
- Criação e execução de uma API utilizando C# e .NET.
- Comunicação entre frontend e backend por meio de uma API REST.
- Utilização dos métodos HTTP GET e POST.
- Integração com o MongoDB para persistência de dados.
- Configuração do ambiente de desenvolvimento e execução local da aplicação.
